## What it does

`main.py` writes a single line of text — one star review, in the cat's own
voice — to `/output/entry.txt`. The complaint is specific (the food bowl was
moved two inches to the left) and the sting lands in the last few words: the
cat has starved for three days beside a full bowl, out of principle.

## Run

```sh
python3 main.py
```

Deterministic, no network, no external dependencies. Output is one line,
111 characters.
